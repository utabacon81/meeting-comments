# Meeting Comments

Suggested comments for the audience-participation parts of each week's meetings, at three levels: Simple, Short, and Complex.

A personal family project. Not an official jw.org site.

## How it is updated

Everything that changes week to week is in `content.js`. The app (`index.html`) reads it, so a weekly update only edits `content.js`.

- Each part lists its questions (paragraph numbers for the Watchtower and Congregation Bible Study).
- Each question has comments under `s` (Simple), `h` (Short), and `x` (Complex).
- A comment starting with `*` is a Recommended pick, 2-3 per part per level.
- Prompts and comments are written in our own words. The site links to wol.jw.org for the printed material.
